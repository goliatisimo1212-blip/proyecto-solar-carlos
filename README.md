# Sistema de Captación y Ahorro Solar - Ley 1715

Plataforma Web para evaluación financiera de proyectos solares fotovoltaicos bajo el esquema CAPEX Cero e incentivos tributarios de la Ley 1715 en Colombia.

## Estructura del Proyecto
- `index.html`: Calculadora web pública para clientes/leads.
- `admin.html`: Panel de administración de prospectos.
- `server.js`: Servidor API REST con base de datos SQLite integrados.
- `package.json`: Configuración de dependencias de Node.js.
- `render.yaml`: Configuración de despliegue automático en la nube.
